# Переделка зарплаты: контрольные примеры

Начать с [точки входа](payroll-redesign.md) и [матрицы требований](payroll-redesign-requirements.md).
Сценарии `C-01`–`C-13` сохраняют правила и примеры инструкций заказчика. Начиная с `C-14`
приведены синтетические примеры принятых пользователем решений с указанием источника. Числовые примеры PDF не задают правила округления для других входных
значений. Эти сценарии предназначены для будущих тестов, но пока не доказывают реализацию.

комбинации; невыполнение личного плана рассматривается отдельно в `C-04`.

| `C-02` | Оборот выполнен, общий план по допам не выполнен | 15% | 500 ₽/ед. | 300 ₽/ед. | `NEW-PDF` §5, с. 2 |
