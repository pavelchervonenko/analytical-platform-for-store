# Согласованность блока «План месяца» и раздела «План»

Статус: реализация и итоговая проверка завершены 2026-09-14.

## Цель и границы

План фиксирует согласованную переработку месячного плана на главной странице и в отдельном
разделе. Он не меняет настройки целей, бизнес-формулы backend и раздел «Смены».

## Обязательные инварианты

1. Расчет определяется магазином, календарным месяцем, датой расчета и охватом.
2. Для недели или произвольного диапазона опорным считается месяц даты окончания.
3. Блок «План месяца» использует общий переключатель охвата раздела «Обзор».
4. Раздел «План» имеет собственный переключатель с режимом `SELLERS` по умолчанию.
5. Переход из блока передает магазин и месяц, но не переносит охват.
6. При одинаковых четырех параметрах оба экрана показывают одинаковые backend-значения.
7. Frontend не рассчитывает собственный прогноз.
8. Настройки плана остаются без изменений.

## Порядок реализации

1. Ввести строгую проверку месяца и единое вычисление опорного месяца и даты расчета.
2. Перевести блок «План месяца» на вычисленный контекст без изменения связи с переключателем
   «Обзора».
3. Добавить в «Обзор плана» собственный переключатель `SELLERS` и `STORE`.
4. Использовать один plan-progress endpoint и одинаковое форматирование на обоих экранах.
5. Добавить процент выполнения и прогноз выполнения выручки.
6. Добавить прогноз суммы для аксессуаров, услуг и дополнительной выручки.
7. Для закрытого месяца заменить прогнозы итогами; недоступные значения не подменять нулями.
8. Покрыть период, охват, переходы, пустые состояния и качество данных тестами.
9. Обновить current-контракты и выполнить локальное визуальное ревью трех размеров экрана.
10. Провести итоговое code review и сверку реализации с этим документом.

## Контрольные сценарии периода

| Выбор в «Обзоре» | Опорный месяц |
|---|---|
| Полный месяц | Выбранный месяц |
| Часть одного месяца | Месяц даты окончания |
| Неделя на стыке месяцев | Месяц даты окончания |
| Диапазон на несколько месяцев | Последний затронутый месяц |
| Диапазон на стыке годов | Месяц и год даты окончания |

Текущий месяц считается до последнего завершенного и загруженного дня. Закрытый месяц считается
целиком. Недельный или пропорциональный месячный план не создается.

## Критерий закрытия

Код, компонентные и граничные тесты, current-документация и локальные desktop, tablet и mobile
снимки подтверждают все инварианты. Итоговое ревью не находит самостоятельных frontend-формул,
скрытого переноса охвата или расхождения месяца между экранами.
