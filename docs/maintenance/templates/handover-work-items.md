# Шаблон остатка работ

Создать `docs/maintenance/project-handover/work-items.md` как `working/draft` по
[общему working-шаблону](working.md). Одна строка = одна проверяемая задача. Решение заказчика
нельзя вывести из существующего кода.

## Правила статуса

`todo` — готово к началу; `blocked` — нет решения/доступа/данных; `in-progress` — есть локальная
работа; `verification` — готово к проверке; `done` — критерий выполнен со ссылкой на evidence.
Приоритет, статус реализации и факт production-выпуска — разные поля.

|---|---|---|---|---|---|---|
| `H-001` | <результат, ссылки> | <статус, приоритет> | <ID/ADR/открытый вопрос> | <роль> | <действие> | <тест/evidence> |
