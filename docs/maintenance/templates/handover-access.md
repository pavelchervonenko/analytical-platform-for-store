# Шаблон реестра доступа и ключей

Создать `docs/maintenance/project-handover/access-register.md` как `working/draft` по
[общему working-шаблону](working.md). Соблюдать
[secrets and key custody](../../security/secrets-and-key-custody.md) и
[access runbook](../../runbooks/access-and-break-glass.md). В Git разрешены только метаданные;
реальные значения, приватные ключи, recovery codes и персональные учётные данные передаются
через утверждённый защищённый канал вне репозитория.
