5. Собрать immutable backend/web images стандартным release workflow из одного commit.
6. На production зафиксировать текущие digest/flags, проверить `docker compose config` и backup.
7. Выполнить стандартный deploy; Flyway должен остаться на `V44`, потому что новых миграций нет.
